# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1** as its code of conduct:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

In short: be welcoming, be respectful, assume good faith, and keep critique about the work, not the person.
Harassment of any kind isn't tolerated.

**Reporting:** contact the maintainers privately through GitHub. Use a private security advisory if
the report is sensitive, or email the address listed in the repository profile. Reports are handled
confidentially, and enforcement follows the Covenant's enforcement guidelines.
